整理日: 2026-10-17

[画像一覧を開く](index.html)。各画像から原寸PNGへ移動できる。[機械可読台帳](manifest.json)に寸法、SHA-256、PPTX内の元パス、スライド番号を記録した。

## 出典

リポジトリルートの `Cycle_Lover.pptx` から抽出。既存の `Cycle Lover.pptx` と、下記11画像のSHA-256がすべて一致することを確認した。PPTX全体の一致やGoogleスライドとの同期を保証するものではない。

PPTXの埋め込み画像をバイト単位でコピーした。再圧縮、拡大、背景除去、描き直し、スライド上のトリミング適用は行っていない。スライド番号は先頭を1とする実際の表示順。抽出元PPTXのSHA-256は台帳に記録。

## 利用方法

1. 原画は `originals/` を参照し、顔、髪型、体格、衣装、配色の基準にする。
2. 制作用の派生画像は別ファイルで作り、原画を保持する。
3. ゲーム用にする際は背景透過、1画像1人物への分離、足元・大きさ・余白の統一を行う。寸法・表示条件は [25の仕様](../ProjectDocs/25_macOS表示・素材制作仕様.md) に従う。
4. 制作者、利用許諾、商用利用、加工可否を確認して台帳へ追記する。PPTXへの掲載だけでは権利確認済みとしない。現在はすべて未記録。

全11画像はRGBでアルファチャンネルがなく、背景付き。原寸は高さ1536px、幅864pxまたは1024px。ゲーム用の制作寸法を満たすかは派生素材ごとに確認する。2人並び、上半身のみ、背景付き構図は、そのまま汎用の全身立ち絵として使用しない。

このフォルダはUnityの `Assets/` 外にあり、参照資料として管理する。既存の `hero_bikeshop_neutral.jpg` の表示設定は維持した。新たなゲーム用素材の登録・差し替えは行っていない。

## 原画がない人物

自転車屋の親父、祖母、マスターの母、町おこし担当、ベテランカメラマン、ロードバイク系VTuber、神社の狐は、今回のPPTXに独立した画像原画がない。プロフィールは28〜34ページにある。年間素材台帳の8人物は現行の表示IDであり、企画上の全登場人物を網羅する一覧ではない。

## 再抽出

プロジェクトルートから次を実行する。

```sh
python3 Tools/extract_character_designs.py ../Cycle_Lover.pptx
```

同じ画像の再抽出は可能。既存原画像と内容が異なる場合や画像数が変わった場合は停止する。スライド構成・人物対応が変わった場合は抽出スクリプトの対応表も確認する。
