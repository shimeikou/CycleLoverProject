# 地域イベントと狐の依頼仕様

更新日: 2026-10-21

## 目的

T24として、恋愛・育成とは別の「地域とのつながり」を年間進行へ追加する。サブキャラの助言、町おこし、SNS、取材、オンライン配信、狐の依頼を、外部通信を前提としないゲーム内イベントとして扱う。

## 進行値

- `RegionalContribution`: 店・人・観光に対する地域貢献。
- `PublicAwareness`: SNS、取材、配信で得る知名度。
- `FoxFavor`: 神社の狐から得る加護。
- `CompletedQuestIds`: 完了した依頼ID。同じIDの報酬は二重適用しない。

これらは `GamePlayerData` に保存する周回内の値とし、新しい周回へは引き継がない。セーブ形式はv5とし、v1〜v4は空の依頼記録と0の進行値で補完する。

## イベント

| 種類 | 主なキャラ | 接続先 |
| --- | --- | --- |
| 祖母の町案内 | 祖母 | 全ルートの攻略ヒントと地域進行の導入 |
| 修理教室 | 自転車屋の親父 | 自転車屋の娘の好感度 |
| 地域ライドの軽食 | マスターの母 | カフェのマスターの好感度と回復 |
| 町おこしSNS企画 | 町おこし担当 | 従妹の好感度と知名度 |
| 地域特集の追加取材 | ベテランカメラマン | 女子アナの好感度と知名度 |
| VTuberの合同配信 | ロードバイク系VTuber | ネットのライバルの好感度と知名度 |
| 狐の依頼 | 神社の狐 | 地域依頼2件完了後に受注 |
| 縁を結ぶ祭り | 神社の狐 | 地域貢献3以上で達成し、加護とエンパシーを得る |

## データと検証

- 本文と報酬は `AnnualRegionalActions.json` へ分離する。
- 発生期間、対象ルート、優先度は `AnnualSchedule.json` の条件イベントで定義する。
- 既読イベントの防止に加え、`QuestId` が登録済みなら報酬そのものを再適用しない。
- 各5ルートの支援イベントが対応するヒロインの好感度につながることを自動検証する。
- 祖母のヒントからルート支援、狐の受注、祭り達成までの通し経路を自動検証する。

2026-10-21時点で上記を実装済み。祖母の依頼1件だけでは狐の依頼は始まらず、各ルート支援を加えた完了依頼2件で受注可能になる。地域貢献2では祭りは発生せず、祖母1＋ルート支援2の地域貢献3で達成可能になる正負境界を現行年間データで検証する。地域関連EditModeテスト6件成功、コンパイルエラー・警告なし。

## 残作業

- macOS Player上で発生順、スキップ停止、保存再開後の依頼記録を確認する。
- 本番シナリオ、サブキャラ立ち絵、神社背景、音、演出を投入する。
- 地域進行値を年末結末や下一周の解放に影響させるかは、バランス調整で決定する。
