## 書き方の方針

- PDFの要約ではなく、実装で追いやすい単位に再編集する。
- 断定しづらい箇所は「未確定」や「要確認」と明記する。
- 進捗、テスト件数、次の作業は17だけに書き、ほかの資料からは17を参照する。
- リンクは相対パスで書く（別端末でも開けるように）。
- 新しい資料は次の番号を付け、内容に合うフォルダへ置く。
