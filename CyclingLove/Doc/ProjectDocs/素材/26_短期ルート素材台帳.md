# 自転車屋の娘・短期ルート素材台帳

更新日: 2026-10-20

## 目的

10日短期ルートで使う素材IDを、シナリオJSONと素材制作の間の正本として管理する。画像を差し替えても本文・進行コードは変更しない。制作寸法とキャラクターの受け入れ条件は [25_macOS表示・素材制作仕様.md](25_macOS表示・素材制作仕様.md) に従う。

## 自転車屋の娘の立ち絵

キャラクターIDは `hero_bikeshop`。正本デザインは企画書14ページ。現在使える画像は旧形式の `hero_bikeshop_neutral.jpg` 1枚で、全衣装・表情の代替表示に使う。

新規素材の標準配置は `Assets/Resources/Images/Characters/{CharacterId}/{OutfitId}/{ExpressionId}`。移行中は `{CharacterId}_{OutfitId}_{ExpressionId}` と旧 `{CharacterId}_{ExpressionId}` も読み込む。解決順は標準配置、平坦名、旧形式。指定表情がなければ同じ衣装のneutral、最後に旧neutralへ戻す。

| OutfitId | 必要な表情 | 使用場面 | 状態 |
| --- | --- | --- | --- |
| shop | neutral / strict / troubled / smile | 店内、診断、整備、葛藤 | 未制作。旧neutralで代替 |
| cycling | neutral / strict / smile | 河川敷の指導、ヒルクライム | 未制作。旧neutralで代替 |
| casual | neutral / strict / smile | 挑戦の前夜 | 未制作。旧neutralで代替 |

表情IDへ衣装名を混ぜない。衣装を追加するときは先にこの台帳とJSONの `OutfitId` を更新する。同じイベントの途中で衣装を変えない。

## シナリオ位置

キャンペーンの `ScenarioId` は `bikeshop_short`。日ごとの午前・午後、行動、会話選択後に一意な `NodeId` を割り当て済み。表示要求には `ScenarioId / NodeId / BackgroundId / CharacterId / OutfitId / ExpressionId` をまとめて渡す。

現在のセーブ形式v6は日付、時間帯、選択行動、選択肢、ページ番号に加え、ScenarioId／NodeId／PageIdを保存する。午後は日・行動・選択肢のNodeIdを合成した実行ノードを使う。行動選択画面と午後導入ページではDay側の素材を表示し、行動本文に入ってからAction／Choice側へ切り替える。本文の挿入・並べ替え後もPageIdから同じ文章を探し、見つからない場合はノード先頭へ戻る。内容変更後も同じ地点として扱うNodeIdはリネームしない。

## 音

BGM・環境音・効果音は年間版と共通の論理IDを `Assets/Resources/Content/AudioCatalog.json` で管理する。BGMクロスフェード、環境音、SEの再生経路は実装済みで、実音源が未配置のIDは無音のまま進行する。短期版専用音を増やす場合も、場面コードへパスを書かずカタログへID・アドレス・場面ルールを追加する。
