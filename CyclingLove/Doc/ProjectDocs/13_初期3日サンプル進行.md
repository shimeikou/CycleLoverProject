# 初期3日サンプル進行

この文書は、最小プレイアブル確認用にコードへ入れた最初の 3 日分の仮進行を整理したものです。

## 目的

- 日付進行が成立するか確認する
- イベント ID ルールを固定する
- 導入 3 日分の最低限の流れを共通認識にする

## イベント ID ルール

形式:

`evt_YYYY_MM_DD_timing_連番`

例:

- `evt_2026_04_01_morning_001`
- `evt_2026_04_03_afternoon_001`
