# 3日間試作の実装と検証

> **2026-10-16 注記:** 本書は3日版の記録。実行対象はすでに10日版 `bikeshop_short` へ移行し、実行時の保存枠も `bikeshop_short`。`ThreeDayGameService` は現在テスト補助（`Assets/Tests/EditMode/Fixtures/`）にだけ残る。進行は `CampaignGameService` が担う。テスト件数は本書時点の値で、最新は [29_別端末再開メモ.md](../運用/29_別端末再開メモ.md)。

## 到達点

タイトルから開始し、午前の仕事、午後の行動選択、物語、1日の振り返りを3日間進められる。途中で保存し、タイトルの「続きから」で同じ文章ページから再開できる。

Unityで `Assets/Scenes/InitScene.unity` を開いてPlayを押し、「はじめから」で開始する。保存は手動。タイトルへ戻る前に画面下の保存ボタンを押す。

## 試作の最小仕様

開始は2026年4月1日朝。資金1000、5能力値は各5、体力100、進行フラグなし。午前の仕事→午後の行動選択と本文→夜の振り返り→翌朝を3回繰り返す。本編の特別枠は対象外。

画面操作が完了している本文・行動選択・日次結果・終了画面で手動保存できる。日付、フェーズ、文章ページ、選択行動、数値、フラグを保存する。進行中・保存中の操作は制限する。期待結果は下記の検証結果を参照。

## 実装範囲

- 未接続だった画面参照を設定し、本文、行動選択、振り返り、保存、タイトルボタンを配置した。
- 日付、資金、5能力値、体力を表示する。横長画面でも下部ボタンが収まるようCanvasを設定した。
- 午前の仕事は資金+500、スマート+1。
- 基礎練習は体力-20、フィジカル+2、タフネス+1。
- 町へ行くは体力-10、資金-100、エンパシー+2、アピール+1。
- 家で休むは体力+30（上限100）、タフネス+1。翌朝の回復は+20。
- 3日目には自転車屋の娘との出会いを記録し、3日目の振り返り後に試作終了画面を表示する。
- 古いクリック入力の再処理による報酬の二重付与を防ぐ。
- 保存内容の検証、上書き時のバックアップ、読み込み失敗時の表示を追加した。非同期保存後にメインスレッドへ戻らない不具合を修正した。

`ThreeDayGameService` が試作の進行と報酬を管理する。既存の年間スケジュール基盤とは分離しており、年間進行の完成を意味しない。試作用セーブ枠は `prototype` とし、既存の `slot1` と分けている。本文は動作確認用に作成した草稿。

## 検証結果

EditModeテスト14件が成功（既存5件、新規9件）。進行、報酬、連続入力、資源不足、各進行地点の保存復帰、実ファイルの上書き、欠損・破損データを確認した。

Editor上ではボタン位置の当たり判定を確認してクリックイベントを送り、次の一連の動作を確認した。

1. 開始 → 1日目の基礎練習 → 本文途中で保存 → タイトル → 読み込み。保存前後のプレイヤーデータが完全一致。
2. 2日目に町へ行く → 振り返りで保存 → Play停止・再開でメモリを初期化 → 読み込み。保存前後のデータが完全一致。
3. 3日目に休む → 振り返り → 終了画面。資金2400、フィジカル7、タフネス7、スマート8、エンパシー7、アピール6、体力100、完了イベント6件。
4. タイトル → はじめから。1日目、資金1000、進行記録なしに戻る。

本文・見出し・進行ボタンの全文字について、使用フォントの欠落がないことを確認。最終確認時点でコンパイル失敗なし、Editor Consoleのエラー0件。既存の警告は残る。

画面キャプチャと検証用セーブはローカルの `Doc/Verification/2026-10-14/` に保存（Git管理対象外）。共有する検証結果は本書に記録する。Unity Editor自体の終了・再起動と、配布用ビルドでの動作確認は未実施。
