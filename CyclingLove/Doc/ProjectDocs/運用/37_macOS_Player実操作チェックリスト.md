# macOS Player実操作チェックリスト

更新日: 2026-10-22

T27の残作業（17「次に着手する順番」1）を、最小の手動操作で確認するための手順。ロジックの境界はEditModeテストで確認済みなので、ここでは「Player上で実際に操作でき、終了・再起動をまたいで同じ地点へ戻るか」だけを見る。

## 前提

- 対象は年間版 `annual_base`（内容Version 2）。2026-10-22に祝日と季節イベントを追加してVersionを上げたため、それ以前の `save_annual_base.dat` は復帰を拒否される。
- 保存先はEditorとPlayerで共通の `~/Library/Application Support/DefaultCompany/CyclingLove/`。Editorの「指定日の朝から開始」で作ったセーブを、そのままPlayerで読み込める。
- Playerは必ずウィンドウモードで起動する。

```sh
open Builds/macOS/CyclingLove.app --args -screen-fullscreen 0 -screen-width 1280 -screen-height 720
```

## 準備

1. 既存の保存先を丸ごと退避する。

   ```sh
   mv ~/Library/Application\ Support/DefaultCompany/CyclingLove ~/Library/Application\ Support/DefaultCompany/CyclingLove.before-t27
   ```

2. macOS Universal Playerをビルドし直す（`Builds/macOS/CyclingLove.app`）。ビルド前検証が通り、警告が素材未投入の66参照だけであることを確認する。
3. 各ケースの「開始方法」が「Editorで作成」のものは、次の手順でセーブを作る。
   1. EditorでPlayし、タイトル画面を表示する。
   2. `Tools/Cycling Love/Campaign Tuning` に表の値を入力し、「指定日の朝から開始」を押す。日付は表の「作成日」（確認したい日の前日）。
   3. その日の行動を1つ選び、日次結果を閉じる（自動保存される）。
   4. Playを停止する。Editorを閉じる必要はない。
   5. Playerを起動し、タイトルから続きを選ぶ。

各ケースの前に、保存先の `save_annual_base.dat*` を消すか、別名で退避する。周回記録の `system.dat` はケース6まで消さない。
