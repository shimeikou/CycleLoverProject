## Git管理外のもの

別端末には次のものが無いので、必要に応じて用意する。

| 対象 | 別端末での扱い |
| --- | --- |
| `CyclingLove/Library/` | 初回起動時にUnityが再生成する。数分かかる |
| `CyclingLove/.codex/config.toml` | Codex用のUnity MCP接続設定。使う場合は下記の内容で作り直す |
| `CyclingLove/Doc/Verification/` | 2026-10-14の画面キャプチャと検証用セーブ。結果は19に記録済みなので、再取得は不要 |
| `CyclingLove/Builds/` | macOS試作ビルド。必要なら再ビルドする |
| `CyclingLove/tmp/` | 企画書PDFの作業用抽出物。原本 `CyclingLove/Doc/Cycle Lover.pdf` はGit管理対象 |
| `CyclingLove/UserSettings/`、`Logs/` | 端末ごとの設定とログ。不要 |

`.codex/config.toml` の内容（`unity` のパスは端末に合わせる）:

```toml
[mcp_servers.unity]
command = "/Users/<ユーザー名>/.unity/bin/unity"
args = ["mcp"]

[mcp_servers.unity.tools.build_status]
approval_mode = "approve"
```
