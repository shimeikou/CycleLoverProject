# パラメータ設計

## プレイヤー主要ステータス

PDF 上では以下の 5 つが主要ステータスとして定義されている。

| ステータス | 役割 |
| --- | --- |
| フィジカル | 身体能力、走行能力 |
| タフネス | 根性、踏ん張り、困難耐性 |
| スマート | 知識、判断力、仕事効率 |
| エンパシー | 魅力、共感、コミュニケーション |
| アピール | 知名度、存在感 |

## メタパラメータ

| パラメータ | 役割 |
| --- | --- |
| 体力 | 日々の行動コスト管理 |
| 好感度 | 各ヒロインの関係進行 |
| 資金 | 買い物、カスタマイズ、デートなど |

## 愛車構成

- フレーム
- コンポーネント
- ホイール

## 愛車性能パラメータ

| パラメータ | 役割 | 相性の良い人側ステータス |
| --- | --- | --- |
| 剛性 | パワー伝達、加速 | フィジカル |
| 重量 | 軽さ、登坂、加速 | タフネス |
| 振動吸収性能 | 疲労軽減、長距離適性 | エンパシー |
| 操作性 | 安定性、コーナー、雨天 | スマート |
| 空力 | 高速巡航、最高速 | フィジカル |

## 愛車熟練度

- 同じバイクに乗り続けると成長する
- 役割:
  - プレイヤーと愛車の一体感を表す
  - 性能値だけではない愛着や習熟を表現する
- 想定効果:
  - ステータス補正
  - 専用スキル解放
  - 特定イベントの条件化
