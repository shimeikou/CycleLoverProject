## 愛車性能パラメータ

| パラメータ | 役割 | 相性の良い人側ステータス |
| --- | --- | --- |
| 剛性 | パワー伝達、加速 | フィジカル |
| 重量（実装: 軽さ `Lightness`） | 軽さ、登坂、加速 | タフネス |
| 振動吸収性能（実装: 快適 `Comfort`） | 疲労軽減、長距離適性 | エンパシー |
| 操作性 | 安定性、コーナー、雨天 | スマート |
| 空力 | 高速巡航、最高速 | フィジカル |

## 愛車熟練度

- 同じバイクに乗り続けると成長する
- 役割:
  - プレイヤーと愛車の一体感を表す
  - 性能値だけではない愛着や習熟を表現する
- 想定効果:
  - ステータス補正
  - 専用スキル解放
  - 特定イベントの条件化

## 現在の計算仕様

装備中のフレーム、コンポーネント、ホイールの5性能値を項目ごとに加算して基礎性能とする。性能名は実装上 `Stiffness / Lightness / Comfort / Handling / Aerodynamics`。候補パーツとの比較は、同じSlotだけを候補へ交換した仮構成を計算し、5項目の差分を返す。

熟練度はフレーム・コンポーネント・ホイールの3IDを連結した愛車構成単位で0〜100を保存する。20ごとに熟練レベルが1上がり、上限は5。現段階では熟練レベルを振動吸収性能と操作性へ同じ値だけ加算する。練習・整備・レースイベントの `Effects.BikeMastery` で、実行時に装備している愛車へ加算する。

脚質は主人公の育成値と装備性能から毎回算出し、保存しない。

| 脚質 | 判定スコア |
| --- | --- |
| Sprinter | Physical×2 + Stiffness + Aerodynamics |
| Climber | Toughness×2 + Lightness + Handling |
| Endurance | Toughness + Empathy + Comfort×2 + Handling |
| Technician | Smart×2 + Handling×2 + 熟練レベル |

最大スコアと2位の差が1以下なら `AllRound`、それ以外は最大の脚質とする。この式は初版の比較可能な基準であり、T18のレース計算を調整する際に係数を外部化するか判断する。
